# Лендинг Дмитрия Тынкова

Next.js 16 (App Router, статическая генерация) + Tailwind CSS v4 + GSAP ScrollTrigger.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production-сборка
```

## Где что править

- **Весь текст**: `content/site.ts`. Компоненты трогать не нужно.
- **Фото первого экрана**: три кадра под разные экраны, браузер скачивает только нужный.
  Положите файлы в `public/photos/` и пропишите пути в `content/site.ts`, раздел `photos`:
  - `mobile`: телефоны (до 768 px), вертикальный 4:5, от 1200x1500 px;
  - `tablet`: планшеты и небольшие ноутбуки (768-1279 px), 3:2, от 2000x1333 px;
  - `desktop`: ноутбуки и мониторы (от 1280 px), широкий 2:1, от 2800x1400 px.

  Можно добавить не все: недостающий кадр заменится ближайшим. Поле `position` у кадра
  задаёт, какая его точка остаётся видимой при обрезке (по умолчанию `"50% 30%"`).
- **Аватар в шапке**: квадратное фото от 400x400 px, лицо крупно по центру. Положите в `public/photos/`
  и пропишите путь в поле `avatar` в `content/site.ts`. Пока его нет, в шапке монограмма «ДТ».
- **Логотипы компаний**: файлы в `public/logos/`, подключаются полем `logo` у места работы в `content/site.ts`.
- **Телефон**: по умолчанию скрыт, включается полем `contacts.phone`.
- **Рукописное имя на первом экране**: это векторные контуры шрифта Great Vibes, а не текст,
  поэтому росчерки не обрезаются и имя «пишется от руки». После смены `firstName` или `lastName`
  в `content/site.ts` перегенерируйте контуры: `npm run signature`.
- **Цвета и темы**: токены в начале `app/globals.css` (светлая и тёмная тема).
- **Анимации**: все в `components/ScrollEffects.tsx`. При `prefers-reduced-motion` отключаются.

## Деплой на Vercel

1. Залейте папку в репозиторий на GitHub.
2. На vercel.com: Add New, Project, выберите репозиторий. Фреймворк определится сам, настройки не нужны.
3. Если подключите свой домен, добавьте переменную окружения `NEXT_PUBLIC_SITE_URL=https://ваш-домен`
   (для корректных ссылок в OpenGraph). Без неё используется адрес production-деплоя Vercel.
